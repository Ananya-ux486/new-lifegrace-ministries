# LifeGrace Ministries – Static Website
Pure HTML, CSS and JS. Open `index.html` (no build or server needed).

Pages: index, about, services (+ sunday-service, thursday-service, youth-ministry), events, lords-city, counselling,
vacancies (+ 3 detail pages), contact, donate, gallery.
Shared styles: css/style.css | Shared scripts: js/main.js | Media: img/, video/

Donation links (unchanged from the old site): Lord's City -> https://pleasegofundme.com/#lords-city-adoration-ground ,
Church -> https://www.lifegraceministries.com/
Contact form opens the visitor's email app addressed to info@lifegraceministries.com (same as the old site).
